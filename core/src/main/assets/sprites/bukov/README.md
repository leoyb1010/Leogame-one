# Bukov enemy sprites

Original project-generated pixel art. Rebuild with:

```shell
node scripts/generate_bukov_enemy_sprites.mjs
```

All six sheets use 16x18 frames: idle 0-1, attack 2-3, run 4-7, death 8-10.
They were drawn from geometric primitives and do not contain host-dungeon
Rat/Goo/Gnoll/Guard pixels.
