## 1. 最终结论

《Leo的地牢围攻》不应停留在“原作换名字、换图标”的层面。个人专属版应围绕四个核心感受建立自己的身份：

1. **一眼能认出是 Leo 的游戏**：狮首、翡翠火、古金、攻城纹章形成统一品牌语言。
2. **每一次攻击都有重量**：命中瞬间同时具备动作、停顿、闪光、粒子、声音、震动与数字反馈。
3. **真正围绕“地牢围攻”形成玩法差异**：加入围攻事件、据点、突围和狮印成长，而不是只修改文本。
4. **是一个私密、离线、长期可玩的个人版本**：无广告、无强制账号、无默认上传，存档可本地备份和导出。

推荐执行顺序是：

**Leo 身份圣经 → 品牌首页与专属仪式 → 打击感垂直切片 → 全武器反馈接入 → Apple UI 精修 → 个人档案与狮令 → 围攻玩法与原创内容 → 发布加固。**

先做一套可以反复对比的“高清 + 强打击感”垂直切片，再批量改造全游戏。这样能尽早确定风格，避免大量素材和代码返工。

## 2. 当前已完成的产品基线

以下内容作为后续升级不可回退的基线：

- 游戏名已统一为“Leo的地牢围攻”。
- Apple Bundle ID 已统一为 `leogameone`。
- 默认语言为简体中文，设置中只提供简体中文和英文切换。
- 中文资源已按现有资源组完成键覆盖校验。
- 原作标题 Logo 已从标题页与欢迎页移除，当前使用动态中文标题。
- 原作新闻与更新源已关闭，避免个人版本继续访问原作线上服务。
- iPhone/iPad 已使用真实 Apple 安全区数据，四角、刘海、Dynamic Island 和 Home Indicator 区域不再直接承载核心 UI。
- iPhone 标题页、游戏页、iPad 页面及 Apple Silicon Mac 构建已完成基础运行验证。

- 不破坏现有存档读取。

- 纯表现层功能不得改变伤害、命中、护甲、回合耗时和掉落概率。
- 中文永远是首次启动默认语言；英文切换必须完整可逆。
- 离线状态下可完成正常游戏、存档、读档与设置调整。

## 3. 个人专属版产品定位

### 3.1 一句话定位

**一款为 Leo 定制、中文优先、完全离线、兼具精致像素美术与强烈战斗反馈的单人地牢围攻 Roguelike。**

### 3.2 核心玩家承诺

- 买断式/个人使用体验，不插入广告，不做强制内购。
- 无需注册账号，不要求联网，不默认上传存档和日志。
- 每局仍保留 Roguelike 的随机、风险和策略深度。
- 失败可以复盘，成长来自理解系统，而不是付费数值。
- Apple 三端共享同一套视觉和玩法规范，但针对屏幕与输入方式分别适配。

### 3.3 品牌关键词

| 维度 | 关键词 | 禁止方向 |
|---|---|---|
| 身份 | 狮王、Leo、私人纹章、远征记录 | 通用奇幻 Logo、廉价金色渐变 |
| 世界 | 地下堡垒、围攻、古代王国、翡翠火 | 现代军事、科幻枪械 |
| 色彩 | 深炭黑、旧铜金、翡翠绿、暗红 | 大面积高饱和霓虹 |
| 质感 | 石刻、旧金属、皮革、羊皮纸、像素光影 | 光滑塑料、扁平网页风 |
| 战斗 | 干脆、沉重、节制、层次清楚 | 高频乱震、满屏闪白、拖慢回合 |

### 3.4 三个版本层级

1. **基础可玩版**：中文、Apple 三端、安全区、可构建、可存档。
2. **个人专属版**：高清品牌视觉、Leo 档案、狮印、离线记录、专属设置和打击感。
3. **原创内容版**：围攻事件、专属英雄、敌人、Boss、章节叙事和结局。

本总纲的目标是完成第 2 层，并为第 3 层建立可持续扩展的技术结构。

### 3.5 什么才算“Leo 自己的游戏”

“自己的游戏”不能只靠标题里出现 Leo，也不能只靠换一套图片。玩家应在五个层面持续感受到同一个作者身份：

| 层级 | 要回答的问题 | 在游戏中的证明 |
|---|---|---|
| 品牌身份 | 这是谁的作品？ | 狮首徽记、专属色、标题、声音标识、启动仪式 |
| 世界身份 | 为什么这个地牢属于这个版本？ | 翡翠火、狮印守卫、地下王庭、围攻历史 |
| 玩法签名 | 它玩起来有什么只有这里才有？ | 狮令决策、围攻据点、守城/突围双路线 |
| 个人记忆 | 游戏是否记得 Leo 的经历？ | 远征档案、个人纪录、纪念品、胜利证书 |
| 情绪仪式 | 开局、失败和通关是否有专属感？ | 宣誓、战报、悼词、凯旋页、下一次远征 |

如果某项改动只能回答“图换了没有”，却不能回答以上任何一个问题，就不应作为专属版的优先任务。

### 3.6 Leo 身份圣经

在继续生成和接入素材前，先冻结一页不可随意漂移的身份圣经：

| 项目 | 第一版建议 | 使用位置 |
|---|---|---|
| 核心徽记 | 正面狮首 + 断裂王冠/城墙轮廓 | App Icon、标题、档案、通关章 |
| 核心火焰 | 翡翠火 | 标题背景、据点、狮令能量、Boss 关键物 |
| 主色 | 深炭黑 `#111414` | 背景、金属阴影 |
| 品牌金 | 旧铜金 `#B58A45` | 边框、重要标题、纹章 |
| 品牌绿 | 翡翠绿 `#2E9B73` | 火焰、能量、交互高亮 |
| 危险色 | 暗血红 `#8F3131` | 受伤、围攻警报、失败 |
| 核心语气 | 克制、坚定、带一点孤独远征感 | 中文文案、旁白、结算 |
| 核心动作 | 守住、破阵、归旗 | 狮令、围攻目标、成就 |
| 核心象征 | 狮首、旧旗、城门、火盆、地下王庭 | 场景、道具、UI 装饰 |

首版标语建议：**“守住最后的火，走完自己的远征。”**

标语应放在首次启动、档案首页或通关结算中，不要在每个页面重复。后续若 Leo 提供更个人化的座右铭，只需要替换身份配置，不重新修改各页面代码。

### 3.7 专属命名体系

统一命名能让游戏从原作术语中逐渐长出自己的世界。第一阶段不必一次改掉所有物品名称，应先替换最高频、最能建立身份的入口词：

| 通用概念 | Leo 专属命名建议 | 说明 |
|---|---|---|
| 开始游戏 | 开始远征 | 建立“每一局是一场远征” |
| 继续游戏 | 继续远征 | 标题页主操作 |
| 游戏记录 | Leo远征档案 | 个人历史入口 |
| 成就 | 狮印荣誉 | 与品牌徽记统一 |
| 每日/特殊挑战 | 王庭试炼 | 纯离线可生成 |
| 新手引导 | 初征手册 | 比“教程”更有世界感 |
| 存档备份 | 远征快照 | 对应存档保险箱 |
| 结算页 | 远征战报 | 胜败都使用 |
| 特殊战术资源 | 狮令 | 本局内的专属决策资源 |
| 据点核心 | 翡翠火盆 | 围攻玩法目标 |

命名规则：中文短、可读、能自然放进按钮；英文不做逐字硬译，而采用统一的 `Leo / Lion Sigil / Expedition / Emerald Flame` 词汇表。

### 3.8 专属世界观最小闭环

第一版只需要建立足够支撑标题、围攻与结局的最小世界观，不急于写百科全书：

- 地下王庭曾依靠翡翠火维持道路、记忆和防线。
- 王庭崩塌后，各层地牢不再只是自然区域，而是被遗弃的防区。
- 狮印持有者能够唤醒据点、记录远征，并在危急时下达狮令。
- Leo 不是旁观者名字，而是这套远征记录的主人和最后授权者。
- 每次下地牢既是寻找力量，也是逐步收复失落防区。
- 最终选择不是简单“拿到宝物”，而是决定重燃王庭、封存力量或继续远征。

这六条足以指导首页、章节标题、围攻目标、档案和双结局。新文本如果与其冲突，必须先更新世界观圣经。

### 3.9 玩法签名：狮令，而不是纯数值光环

为了让“Leo 定制”真正进入每回合决策，新增本局内战术资源“狮令”。它不是付费货币，也不是永久加攻击力。

狮令通过主动承担风险获得，例如：

- 在低生命状态完成击杀。
- 无伤守住一波围攻。
- 主动打开额外进攻路线。
- 完成区域的自选战术目标。

第一版只提供三条命令：

1. **守住**：短时间强化防守或保护据点，强调稳住阵线。
2. **破阵**：标记一个方向/目标，使下一次有效重击获得表现与战术强化。
3. **归旗**：在围攻中重整站位或恢复一处已失效的战术节点，不等同于免费复活。

设计约束：

- 狮令每局重新开始，不出售、不联网、不形成付费压制。
- 三条命令都必须改变玩家决策，不能只是“伤害 +10%”。
- 标准模式可以关闭狮令，保留接近原作的纯 Roguelike 体验。
- 狮令拥有自己的翡翠火音画反馈，成为这个版本的玩法声音签名。

### 3.10 专属角色关系

不要把 Leo 简单制作成一个写实真人角色。更耐用的方式是让 Leo 成为“远征档案与狮印的主人”，游戏中的英雄是受其授权的远征者。

这样可以同时保留：

- Leo 的明确所有者身份。
- 多职业、多英雄选择。
- 奇幻世界的代入感。
- 以后加入个人彩蛋而不破坏主线。

首名原创英雄建议命名为“狮卫”，其视觉和技能围绕守阵、反击与狮令联动，而不是直接复制战士换皮。

### 3.11 五个专属仪式

#### 首次启动：授印

- 黑场中先出现一簇翡翠火。
- 火光勾勒狮首纹章。
- 显示一次标语与离线隐私承诺。
- 玩家点击“接受狮印”，进入首页；之后不重复强制播放。

#### 每局开始：出征

- 显示英雄、种子、当前挑战和一句短宣言。
- 可快速跳过，不打断重复游玩。

#### 关键围攻：燃火

- 点燃翡翠火盆后，UI 边框和短音型发生一次变化。
- 明确告诉玩家这是专属机制，而不是普通房间战斗。

#### 失败：留档

- 不只显示死亡，而是生成简短远征战报。
- 记录最深层、关键敌人、代表武器和一个值得记住的瞬间。
- 文案克制，不嘲讽玩家。

#### 通关：凯旋

- 生成带狮印编号的本地胜利证书。
- 显示本局关键决策和个人纪录。
- 可导出图片，但默认不分享、不上传。

### 3.12 个性化配置层

把会随 Leo 个人偏好变化的内容集中配置，避免将名字、标语和日期散落硬编码：

```text
LeoIdentityConfig
  displayName       = "Leo"
  gameTitleZh       = "Leo的地牢围攻"
  mottoZh           = "守住最后的火，走完自己的远征。"
  emblemStyle       = "lion_emerald"
  accentPalette     = "charcoal_gold_emerald"
  archiveTitleZh    = "Leo远征档案"
  ownerMode         = true
```

可配置内容仅用于身份呈现，不应包含密钥、真实隐私或需要联网验证的数据。生日/纪念日彩蛋如果启用，只保存在本地，并提供关闭入口。

### 3.13 定制感密度规则

专属元素需要“关键时刻高密度、普通游玩低干扰”：

- 首页、首次启动、档案、围攻、Boss 和结算：高密度表达 Leo 身份。
- 普通探索、背包和战斗 HUD：只保留小型纹章、配色和声音语言。
- 不在每个物品名里加入 Leo，不在每句话里重复狮子，不让品牌元素压过信息。
- 同屏最多一个主要狮首，避免徽记滥用后失去价值。
- 翡翠火只用于“授权、据点、狮令、记忆”四类含义，不能成为任意装饰光效。

## 4. 升级设计原则

### 4.1 原生像素，而不是模糊放大

- 角色、怪物、地砖和道具保持像素画规则，采用整数倍缩放。
- 章节插画、标题背景、图标和非像素 UI 使用高清源图。
- 不对 sprite 图集直接做普通 AI 超分后上线；如需升级，必须重绘并逐帧检查轮廓、锚点和碰撞视觉。
- 所有纹理进入运行时前统一色彩空间、尺寸、alpha、压缩和体积预算。

### 4.2 打击感不等于震得更厉害

好的打击感来自“攻击预备—接触—受击—结果”的清晰节奏。屏幕震动只是其中一个通道，而且必须允许关闭。

### 4.3 表现层与战斗层隔离

- 战斗层只负责命中、伤害、格挡、暴击/奇袭、死亡等结果。
- 反馈层读取结果并播放表现，不反向改变战斗结果。
- 命中停顿只冻结/减速表现时钟，不冻结 Actor 调度，不修改回合时间。
- 所有反馈都由一个统一入口调参，避免特效散落在数十个武器类中。

### 4.4 Apple 三端一致，但不强求同一种布局

- iPhone 优先单手触控、最小触控尺寸和安全区。
- iPad 利用更宽空间展示信息，不简单等比放大手机 UI。
- Mac 支持鼠标、键盘、全屏和窗口缩放；像素内容仍保持锐利。

### 4.5 可访问性优先

- 屏幕震动、命中停顿强度、震动、闪光和伤害数字均可调或关闭。
- “减少动态效果”模式应同时降低位移、震动、闪光和粒子数量。
- 重要战斗信息不能只依赖颜色或震动表达。

## 6. 打击感系统完整设计

### 6.1 当前代码基础与缺口

现有工程已经具备可复用能力：

- `Char.attack(...)` 能拿到命中、格挡、有效伤害、目标是否死亡等核心结果。
- `KindOfWeapon` 已有武器命中音效和音高参数。
- `CharSprite` 已有攻击动画、闪白、血花和动作完成回调。
- `PixelScene.shake(...)` 已接入用户的屏幕震动强度设置。
- `IOSPlatformSupport.vibrate(...)` 已能触发 iOS 震动/触感或控制器震动。
- 资源中已有斩击、刺击、钝击、魔法、强击和格挡等基础声音。

当前缺口：这些反馈分散在攻击者、武器、技能和敌人代码中，没有统一的命中上下文、强度分级、材质层、设备策略和可调参数。

### 6.2 推荐技术结构

新增一个轻量的表现层入口，不修改伤害公式：

```text
战斗结算
  -> 生成 HitFeedbackContext
  -> CombatFeedback.play(context)
       -> 动画反馈
       -> 命中停顿
       -> 屏幕震动
       -> 粒子/闪光/伤害数字
       -> 音效分层
       -> iOS/控制器触感
```

`HitFeedbackContext` 至少包含：

- 攻击者与目标位置。
- 命中、未命中、格挡、免疫、造成伤害、击杀。
- 实际伤害、目标最大生命、伤害占比。
- 攻击类别：斩击、刺击、钝击、投射、魔法、爆炸、环境。
- 目标材质：血肉、骨骼、护甲、石质、软泥、灵体、木质。
- 强度：轻、标准、重、暴击/奇袭、终结、Boss 重击。
- 是否由英雄造成、是否发生在镜头内、是否允许震动。

建议代码落点：

- 新增 `effects/combat/CombatFeedback.java`：统一分发。
- 新增 `effects/combat/HitFeedbackContext.java`：只存一次命中结果。
- 新增 `effects/combat/HitFeedbackProfile.java`：集中保存强度参数。
- 在 `Char.attack(...)` 完成实际伤害计算后调用反馈入口。
- 在特殊技能中只传入覆盖参数，不重复实现震动和音效组合。

### 6.3 一次攻击的四段节奏

#### A. 攻击预备

- 轻武器：短促前倾，预备不超过 40–60 ms。
- 重武器：增加 70–110 ms 蓄力感，但不改变逻辑回合耗时。
- 远程：投射物离手前给出清晰的起手帧。
- 魔法：先出现能量聚集，再在命中点爆发。

#### B. 接触瞬间

- 攻击者向目标方向推进 1–2 个逻辑像素。
- 目标沿受力方向后挫 1–3 个逻辑像素，然后回到格子中心。
- 播放短命中停顿、接触闪光和瞬态音效。
- 粒子方向必须与攻击方向一致，不做无方向的圆形喷溅。

#### C. 受击恢复

- 目标闪色 1 次，不连续高频闪烁。
- 重击可有一次 95%→105%→100% 的像素安全缩放；普通攻击不需要夸张拉伸。
- 血花、碎屑或魔法粒子根据目标材质选择。
- 伤害数字在接触后立即出现，移动距离短，避免遮挡棋盘信息。

#### D. 结果确认

- 击杀：比普通命中多一层低频声音、粒子和略长停顿。
- 格挡：金属火花、硬质声、极短反向位移，不播放血花。
- 未命中：挥空声与轻微动作过冲，不震屏、不触发重震动。
- 免疫：冷色反馈和“免疫”文字，不使用命中红光。

### 6.4 命中停顿参数

命中停顿必须只影响视觉表现，不能使用线程阻塞、`sleep`，不能停止 Actor 队列。

| 事件 | 建议停顿 | 说明 |
|---|---:|---|
| 轻击命中 | 25–35 ms | 匕首、飞镖、小型怪物攻击 |
| 标准命中 | 40–55 ms | 剑、斧、普通法术 |
| 重击命中 | 65–85 ms | 锤、巨剑、蓄力攻击 |
| 暴击/奇袭 | 90–115 ms | 必须有明显但不拖沓的确认感 |
| 普通击杀 | 75–100 ms | 与死亡动画起点对齐 |
| Boss 终结 | 120–140 ms | 上限 140 ms，防止破坏节奏 |
| 格挡/招架 | 35–50 ms | 强调硬碰撞，随后立即恢复 |

约束：

- 连续攻击时采用衰减，300 ms 内第二次反馈降至 75%，第三次降至 55%。
- 多目标 AoE 只按主目标播放一次全局停顿和震屏，其他目标只播放局部反馈。
- “减少动态效果”模式下停顿减半；“关闭命中停顿”时完全跳过。

### 6.5 屏幕震动参数

| 强度 | 幅度建议 | 时长建议 | 使用场景 |
|---|---:|---:|---|
| 无 | 0 | 0 | 挥空、毒伤、持续伤害 |
| 轻 | 0.15–0.25 | 60–90 ms | 普通近战命中 |
| 中 | 0.35–0.55 | 90–130 ms | 重武器、强法术 |
| 重 | 0.7–1.0 | 130–180 ms | 暴击、精英击杀 |
| 特殊 | 1.2–1.8 | 180–260 ms | Boss 落地、场景坍塌，不用于普通攻击 |

要求：

- 优先沿攻击方向震动，再加入极小随机扰动。
- 调用现有 `SPDSettings.screenShake()` 作为全局倍率。
- 同屏多次震动要合并取最大值，不能简单叠加导致镜头失控。
- iPhone 小屏默认强度低于 Mac/iPad 约 15%。

### 6.6 武器手感矩阵

| 类别 | 动作 | 停顿 | 音效 | 粒子 | 震动 |
|---|---|---|---|---|---|
| 斩击 | 横向弧线、短推进 | 中 | 金属切入 + 血肉层 | 弧形血点/碎布 | 轻到中 |
| 刺击 | 直线突进、快速回收 | 短而尖 | 高频穿刺 + 细小冲击 | 方向集中的细粒子 | 极短轻震 |
| 钝击 | 慢起手、强后挫 | 较长 | 低频撞击 + 材质碎裂 | 石屑/骨屑/尘土 | 中到重 |
| 投射 | 出手与命中分离 | 命中时短停顿 | 飞行声 + 接触声 | 单方向火花/血点 | 仅英雄命中时轻震 |
| 魔法 | 聚能、命中扩散 | 依技能级别 | 能量瞬态 + 元素尾音 | 元素专属粒子 | 中等、持续短 |
| 格挡 | 反向弹开 | 35–50 ms | 清脆金属/硬质声 | 火花，不出血 | 单次清晰触感 |

### 6.7 目标材质矩阵

目标材质由怪物基类/属性声明，默认值为血肉，特殊敌人显式覆盖：

| 材质 | 声音主体 | 视觉主体 | 禁用反馈 |
|---|---|---|---|
| 血肉 | 湿润冲击、布料 | 暗红血点 | 过亮火花 |
| 骨骼 | 干脆骨裂 | 骨屑、灰尘 | 大量血花 |

### 6.8 音效分层

每次重要命中最多由四层组成：

1. **瞬态层**：决定攻击是否“脆”，长度极短。
2. **武器层**：斩、刺、钝、箭、法术。
3. **材质层**：血肉、骨骼、金属、石头、软泥。
4. **重量尾音**：只用于重击、暴击、击杀和 Boss，不应用于每一刀。

混音规则：

- 单次命中音量总和不能削波；多层使用预留余量。
- 普通音高随机建议控制在 ±4%，不使用过大的随机范围破坏武器身份。
- 连续命中对相同音效做轻微音高轮换，避免“机关枪式重复”。
- 音效文件统一无多余静音头，接触瞬态在播放后 10 ms 内到达。
- iPhone 外放重点检查中频清晰度；低频不能只在耳机上成立。

素材命名建议：

```text
hit_slash_light_01.wav
hit_slash_heavy_01.wav
impact_flesh_01.wav
impact_armor_01.wav
impact_bone_01.wav
finisher_low_01.wav
parry_metal_01.wav
```

母带保留 WAV，运行时再按工程格式转换。每组至少 3 个近似变体。

### 6.9 iPhone/iPad 触感

| 事件 | 触感建议 | 备注 |
|---|---|---|
| 普通命中 | 轻触感 | 仅玩家主动攻击且命中 |
| 重击/暴击 | 中触感 | 不连续叠加 |
| 格挡/招架 | 清晰短触感 | 与金属声同步 |
| 玩家受重伤 | 中到重触感 | 生命危险时可加强 |
| 击杀普通敌人 | 默认不额外加强 | 避免每回合都震 |
| Boss 终结 | 单次重触感 | 作为稀有奖励反馈 |

设置项：`关闭 / 轻 / 标准 / 强`。默认“标准”，减少动态效果时自动降一级。iPad 无可用触感能力时静默跳过，不影响流程。

### 6.10 伤害数字与文字

- 普通伤害：米白或浅红，小幅上移。
- 重击：字号增加 10%–15%，不使用巨大遮屏数字。
- 暴击/奇袭：旧金色描边，并显示“暴击”或对应中文事件词。
- 护甲吸收/格挡：灰蓝色，避免与真实伤害混淆。
- 治疗、护盾和伤害必须拥有不同图形/文字特征，不能只靠颜色。
- 多段伤害在 200 ms 内可合并显示总值，但日志仍保留每段结果。

### 6.11 打击感设置页

新增“战斗反馈”设置组：

- 命中停顿：关 / 轻 / 标准。
- 屏幕震动：沿用现有强度设置。
- 触感反馈：关 / 轻 / 标准 / 强。
- 受击闪光：关 / 低 / 标准。
- 伤害数字：关 / 精简 / 完整。
- 粒子密度：低 / 标准 / 高。
- 减少动态效果：总开关，并覆盖上述高强度选项。

### 6.12 打击感垂直切片

首个切片只覆盖以下组合：

- 英雄：战士。
- 武器：短剑或长剑、匕首、战锤。
- 敌人：老鼠（血肉）、骷髅（骨骼）、装甲敌人（护甲）、软泥怪（软泥）。
- 事件：普通命中、未命中、格挡、重击、击杀、玩家受击。
- 平台：一台 Dynamic Island iPhone、一台 iPad、Apple Silicon Mac。

垂直切片验收：

- 关闭声音后，仍能仅靠动作与画面区分轻击和重击。
- 关闭画面后，仅靠声音能区分斩击、刺击、钝击和格挡。
- 三种设备上的输入到反馈没有可感知的额外延迟。
- 20 次连续攻击不会发生镜头漂移、粒子持续残留或声音削波。
- 开关所有反馈选项后，战斗伤害、随机结果和存档完全一致。

## 9. 个人专属功能

### 9.1 Leo 远征档案

本地保存以下统计：

- 总远征次数、通关次数、最深层数。
- 各英雄使用次数、胜率、最长连胜。
- 常用武器、造成总伤害、击败 Boss 次数。
- 最快通关、最少回合通关和个人最佳种子。
- 最近 20 局的关键事件时间线。

数据只保存在本地，可手动导出为 JSON；不默认联网同步。

### 9.2 狮印系统

狮印是个人版的长期象征，不应成为破坏平衡的永久数值外挂。

第一版建议提供三类非付费成长：

- **知识印记**：解锁怪物、道具和围攻事件档案。
- **荣誉纹章**：完成挑战后解锁标题、边框和外观。
- **远征预设**：保存常用 UI、快捷栏和反馈设置，不增加战斗数值。

如果后续加入数值成长，应限定在独立“传承模式”，并与标准 Roguelike 成就和排行榜分开。

### 9.3 本地存档保险箱

- 手动创建带日期和备注的存档快照。
- 导出/导入单个压缩包。
- 导入前校验版本、校验和与 Bundle ID。
- 覆盖前自动创建恢复点。
- 错误日志可导出，不自动上传。

### 9.4 Leo 专属启动体验

- 首次启动执行一次“授印”仪式，并用中文介绍离线、隐私与操作。
- 标题页展示狮首徽记与“继续远征”，而不是通用的“继续游戏”。
- 可选显示个人最佳记录，但不把信息堆满首页。
- 特殊日期彩蛋只读取本地日期，不联网追踪。

### 9.5 远征纪念馆

纪念馆不收藏所有普通掉落，而只保留真正能形成个人故事的内容：

- 首次通关使用的英雄、武器和狮令组合。
- 每个 Boss 的第一次击败记录。
- 最危险的一次残血胜利。
- 围攻据点的最佳守卫结果。
- 已获得的狮印荣誉、结局和纪念品。
- 玩家手动标记的“值得记住的一局”。

展示上采用石墙陈列、旧旗和翡翠火照明，不做成普通数据表。所有数据来自本地档案。

### 9.6 个人胜利证书与远征战报

每局结束生成一个本地战报对象，包含：

- 狮印编号。
- 英雄、种子、难度和日期。
- 最深层数、回合数、代表武器。
- 三个关键事件。
- 本局使用的狮令与围攻结果。
- 一句根据过程生成的中文结语。

通关时可将战报渲染成 9:16 和 1:1 两种图片，使用 Leo 徽记和专属边框。导出是用户主动操作，游戏不集成社交 SDK。

### 9.7 专属声音签名

建立一个 1.0–1.5 秒的短音型，由低沉金属、一次狮吼质感的非写实低频和翡翠火点燃声组成。只用于：

- 首次授印完成。
- 狮令充满。
- 围攻据点成功守住。
- 通关狮印落章。

普通按钮和普通攻击不得播放该声音，保证它始终代表“Leo 专属关键时刻”。

### 9.8 私人彩蛋边界

后续可以加入只对 Leo 有意义的名字、日期、短句、幸运数字或物品，但应满足：

- 不阻断主线，不影响平衡，不要求外部玩家理解。
- 可以从一个本地配置表关闭。
- 不写入真实住址、联系方式、账号或其他敏感信息。
- 彩蛋素材同样进入版权和来源台账。
- 每个区域最多一个轻量彩蛋，避免游戏变成私人信息展示页。

## 10. “地牢围攻”原创玩法

### 10.1 围攻事件核心循环

普通探索中，每个区域安排一次可预判的围攻节点：

1. 玩家发现据点并获得准备回合。
2. 选择修复防线、布置陷阱、寻找补给或提前突围。
3. 敌人从多个入口分波推进。
4. 玩家保护核心目标，或在限定条件下打开撤离路线。
5. 根据剩余防线、耗时和可选目标进行结算。

围攻不能把游戏变成实时塔防；仍使用原有回合制 Actor 系统。

### 10.2 首个可玩围攻章节

建议主题：**翡翠火前哨站**。

- 地图：中央狮印火盆，三条进攻路线，两处可修复障碍。
- 波次：侦察、混合兵、重甲破门者、精英队长。
- 玩家选择：守住火盆、开启侧门突围、牺牲补给换取防线。
- 奖励：知识印记、外观纹章、下一地区的一次性战术优势。
- 失败：不立即结束整局，但失去据点奖励并触发不同后续叙事。

### 10.3 首个 Leo 专属内容包

- 1 名专属英雄：围城者/狮卫方向。
- 1 套专属初始装备。
- 4 个普通敌人：侦察者、破门者、火罐兵、地穴工兵。
- 1 个精英敌人：狮印篡夺者。
- 1 个 Boss：地城攻城王。
- 1 个完整区域故事、开场和双结局。

内容包开始制作前，必须先完成打击感和 UI 组件，否则新增角色仍会绑定旧表现。

## 11. 技术改造地图

| 子系统 | 当前可复用点 | 计划改造 | 主要风险 |
|---|---|---|---|
| 战斗结算 | `Char.attack(...)` | 生成统一命中反馈上下文 | 重复触发、随机序列变化 |
| 武器音效 | `KindOfWeapon.hitSound` | 升级为武器类别 + 材质分层 | 音量削波、特殊武器覆盖 |
| 角色动画 | `CharSprite` | 推进、后挫、闪色、局部停顿 | 回调时序、sprite 锚点 |
| 屏幕震动 | `PixelScene.shake` | 方向、强度分级、合并与衰减 | 镜头漂移、晕动不适 |
| iOS 触感 | `IOSPlatformSupport.vibrate` | 事件强度映射与设置项 | 设备能力差异 |
| 设置 | `SPDSettings` / `WndSettings` | 战斗反馈与减少动态效果 | 老设置迁移 |
| 安全区 | `getSafeInsets` | 建立页面级截图回归 | 旋转与窗口变化 |
| 素材 | 现有 assets 管线 | HD 插画、9-slice、战斗 FX | 体积、授权、色彩空间 |
| 存档 | 现有 Bundle 存储 | 远征档案、快照导入导出 | 版本兼容、覆盖风险 |
| 围攻 | Actor/Level 系统 | 波次、据点、结算对象 | 关卡软锁、性能峰值 |

### 11.1 明确禁止的实现

- 不在主线程中使用 `sleep` 制造命中停顿。
- 不让表现层调用随机数影响战斗 RNG；视觉随机使用独立随机源。
- 不在每个武器类复制同一套屏幕震动和震动代码。
- 不用全屏闪白作为所有重击的默认反馈。
- 不直接覆盖用户存档，不在导入失败时删除原文件。
- 不为了个人功能引入账号、遥测或常驻网络服务。

## 12. 分阶段升级计划

以下工期是单人开发的建议工作量区间，用于排优先级，不是发布日期承诺。

### 阶段 0：冻结基线与回归证据（2–3 个工作日）

目标：在继续修改前建立可对比、可恢复的基准。

任务：

- 记录版本、提交、构建命令和设备信息。
- 建立中英文全页面截图基线。
- 保存固定种子与三份测试存档：新局、中期、Boss 前。
- 记录 10 组典型战斗的伤害和回合结果。
- 建立 iPhone/iPad/Mac 的基础性能数据。

交付物：截图基线、测试存档、回归清单、性能记录。

退出标准：相同种子和操作序列可重复得到相同战斗结果。

### 阶段 1：高清品牌视觉（5–8 个工作日）

目标：解决“模糊”和“仍像原作”的第一视觉问题，同时冻结 Leo 身份语言。

任务：

- 落地身份圣经、品牌词典、标语和专属命名表。
- 接入狮首 App Icon 和 Apple 全尺寸图标。
- 接入横竖标题背景与透明标题徽记。
- 完成首次“授印”与标题页“继续远征”仪式。
- 制作专属短音型的第一版占位/母版。
- 批量处理并接入章节/英雄插画。
- 建立素材校验脚本和授权台账。
- 完成标题、欢迎、章节切换页截图对比。

退出标准：隐藏游戏标题后，仍能通过徽记、配色、用词和启动仪式判断这是 Leo 版本；所有 Apple 目标上图标、标题和插画清晰，无旧标题资产回流。

### 阶段 2：打击感垂直切片（5–7 个工作日）

目标：用最小范围确定整套战斗反馈语言。

任务：

- 建立 `HitFeedbackContext` 和统一反馈入口。
- 完成轻/标准/重/格挡/击杀五档配置。
- 接入战士、三类武器、四类目标材质。
- 接入方向性后挫、局部停顿、粒子和音效分层。
- 接入 iOS 触感和战斗反馈设置。
- 录制三端前后对比视频。

退出标准：通过第 6.12 节的全部垂直切片验收。

### 阶段 3：全战斗反馈接入（7–12 个工作日）

目标：把切片规则安全扩展到现有英雄、武器、技能和主要敌人。

任务：

- 为全部武器声明攻击类别和重量档。
- 为主要怪物声明材质，缺省安全回退为血肉。
- 处理魔法、远程、AoE、持续伤害和反击。
- 为精英、Boss、暴击/奇袭和终结增加专属档位。
- 清理旧的重复 `shake`、`flash`、声音组合，保留特殊场景例外。
- 增加反馈事件的调试显示与自动统计。

退出标准：完整打一局无重复震动、无错材质、无反馈导致的逻辑差异。

### 阶段 4：Apple UI 精修（5–8 个工作日）

目标：完成三端可读性、触控和布局质量。

任务：

- 接入高清 9-slice UI。
- 校准中文字号、行距、按钮和长文本窗口。
- 完成横竖屏、安全区、旋转和 Mac 缩放回归。
- 完善控制器、鼠标和键盘焦点。
- 加入“减少动态效果”和全部反馈设置。

退出标准：设备矩阵全通过，无关键内容遮挡、截断或模糊。

### 阶段 5：个人专属系统（8–12 个工作日）

目标：形成无需联网也能长期积累的 Leo 个人体验。

任务：

- Leo 远征档案与最近战局时间线。
- 知识印记、荣誉纹章和设置预设。
- 狮令的本局资源、三条命令和标准模式关闭选项。
- 远征纪念馆、失败战报和通关胜利证书。
- 本地存档快照、导入、导出和恢复点。
- 个性化配置层、个人最佳记录和隐私说明。
- 中英文全部补齐并执行键覆盖检查。

退出标准：删除网络后仍能完成全部个人功能；错误导入不会损坏现有存档。

### 阶段 6：围攻玩法垂直切片（12–18 个工作日）

目标：交付“翡翠火前哨站”完整事件。

任务：

- 围攻地图生成与可达性验证。
- 准备回合、波次、据点生命和突围路线。
- 4 类敌人/变体和 1 名精英队长。
- 成功、失败、撤退三类结算。
- 章节中文叙事、音效、插画和战斗反馈。

退出标准：至少 30 次自动/人工测试无软锁，三种结局路径均可完成。

### 阶段 7：原创内容包（15–25 个工作日）

目标：让游戏从个人改版进一步成为有原创身份的作品。

任务：专属英雄、装备、Boss、区域剧情、双结局、平衡与本地化。

退出标准：新内容可以独立完成一局，不依赖调试命令，不破坏原有职业通关。

### 阶段 8：发布加固（5–10 个工作日）

目标：形成可归档、可安装、可追溯的 Apple 发布包。

任务：

- Apple 签名、权限、隐私清单、图标和版本元数据。
- 完整离线检查、崩溃日志导出和存档迁移。
- GPLv3 源码发布流程与第三方许可证清单。
- 建立 Leo 自有远端，原作远端只用于获取上游更新。
- 构建 iPhone/iPad archive 与 Mac 发布包。

退出标准：干净环境可以依据文档构建；安装包与对应源码、素材许可证可一一追溯。

## 14. 质量与性能验收

### 14.1 功能回归

- 新建、存储、读取、死亡、重开、通关流程正常。
- 中英文切换后所有新增 UI 都能立即正确显示。
- 固定种子与固定操作序列的战斗结果不因反馈设置变化。
- 无网络时启动、游玩、存档、导出日志均正常。
- Android 未被本轮共享代码意外破坏；如共享 core 必须至少执行编译检查，但不进行 Android 产品改造。

### 14.2 性能预算

- 目标设备正常战斗维持稳定帧率，反馈峰值不造成肉眼卡顿。
- 一次普通攻击的新增短生命周期对象应可控，优先复用 emitter/对象池。
- AoE 同屏 10 个目标时，全局震动和停顿只触发一次。
- 粒子密度“低”适用于旧设备，“标准”为默认，“高”只增加表现不改变信息。
- 音效并发设置上限，避免 Boss 战大量重复声音。

### 14.3 视觉回归

- 标题、游戏 HUD、背包、设置、日志、Boss 战各保留中英文截图。
- iPhone 横竖屏四角、Dynamic Island 和 Home Indicator 无关键遮挡。
- iPad 弹窗不过宽，Mac 缩放不糊。
- 减少动态效果开启后，所有强闪光、强震动和大位移均被降低。

### 14.4 打击感盲测

建议邀请 3–5 名体验者，在不知道配置的情况下完成：

- 判断三种武器中哪一种最重。
- 判断目标是血肉、骨骼还是护甲。
- 判断普通命中、格挡和重击。
- 评价连续 20 次攻击是否疲劳、晕动或过吵。

通过标准：大多数人能正确识别事件，同时没有人认为普通战斗“每一下都过度震动”。

## 15. 存档与兼容策略

- 新字段必须提供缺省值，旧存档没有个人档案时自动初始化。

## 17. “不是换皮”专项验收

个人专属版需要单独通过一次身份验收，不能只用“功能能运行”作为完成标准。

### 17.1 五秒识别测试

向不了解项目的人分别展示 App Icon、标题页和一张游戏截图，每张只看五秒，然后询问：

- 是否能复述狮首、翡翠火或古金中的至少两个元素？
- 是否认为三张图来自同一个游戏？
- 是否能看出这不是通用的 Pixel Dungeon 标题包装？

未通过时优先修正视觉语言一致性，而不是继续增加装饰。

### 17.2 无标题识别测试

隐藏“Leo的地牢围攻”文字，只保留画面、UI、声音与玩法。至少应有三项仍能证明身份：

- 狮首/城墙轮廓形成的独特徽记。
- 翡翠火只在授权、据点、狮令和记忆场景出现。
- “开始远征、狮令、远征战报”等专属用词。
- 守住/破阵/归旗的玩法决策。
- 授印、燃火、留档、凯旋的专属仪式。
- 关键时刻的短声音签名。

如果隐藏标题后只剩下原作地图和原作操作，就仍然属于换皮，不能进入个人专属版里程碑。

### 17.3 原作残留审计

以下位置只允许在版权、许可证和“关于”页面保留原作名称：

- App 名称、窗口标题、启动页、首页 Logo。
- 新闻、更新、捐赠和外部链接。
- 默认分享文案与导出文件名。
- 存档显示名、错误日志标题和设置页。
- 成就、档案、结算与通关证书。

审计不是删除版权声明；GPLv3、原作者署名和第三方许可必须完整保留。

### 17.4 专属触点覆盖表

| 玩家触点 | 必须出现的专属表达 | 不允许只做的事情 |
|---|---|---|
| App Icon | 狮首 + 翡翠火/古金关系 | 只给旧图标换色 |
| 首次启动 | 授印 + 离线承诺 | 只换欢迎文字 |
| 标题页 | 专属徽记、背景、继续远征 | 原作背景上叠新标题 |
| 英雄选择 | 出征卡片、狮印授权 | 只改英雄名字 |
| 游戏 HUD | 克制的小型纹章/狮令入口 | 满屏重复 Logo |
| 普通战斗 | 统一武器和材质反馈 | 只放大屏幕震动 |
| 围攻 | 翡翠火盆、守/破/归决策 | 普通怪物房改名 |
| 档案 | Leo 远征历史 | 只显示通用统计表 |
| 失败 | 远征战报与一句结语 | 只替换 Game Over 字体 |
| 通关 | 狮印胜利证书与关键决策 | 只换结局插画 |
| 声音 | 稀有专属短音型 | 所有按钮都播放 Logo 音 |
| 导出 | Leo 边框、本地生成、无水印广告 | 默认上传社交平台 |

### 17.5 定制完成门槛

以下六项必须全部成立：

1. **视觉成立**：无标题也能识别品牌家族。
2. **语言成立**：高频入口和结算拥有统一的远征用词。
3. **玩法成立**：狮令和围攻至少各有一个完整可玩切片。
4. **记忆成立**：游戏能够本地记住并呈现个人关键经历。
5. **仪式成立**：授印、失败或通关至少有两个完成态仪式。
6. **边界成立**：原作署名保留，但产品入口不再依赖原作品牌与在线服务。

## 18. 完成定义（Definition of Done）

个人专属版达到“完成”必须同时满足：

1. Apple 三端构建和安装成功。
2. 中文首次启动，英文可完整切换，无新增缺失键。
3. 所有核心页面通过安全区和清晰度检查。
4. 斩、刺、钝、投射、魔法、格挡拥有可区分的反馈。
5. 命中停顿、震屏、闪光、粒子、触感均可调整或关闭。
6. 打击感开关不改变伤害、回合、RNG 和存档。
7. 授印、出征、失败战报与凯旋证书形成完整的个人仪式链。
8. Leo 远征档案、狮印和存档保险箱完全离线工作。
9. 狮令拥有至少三条有决策差异的命令，并可在标准模式关闭。
10. 至少一个围攻事件从准备、战斗到结算完整可玩。
11. 通过第 17 节的无标题识别和原作残留审计。
12. 固定种子通关回归通过，无软锁和存档损坏。
13. 源码、构建说明、许可证和素材权属可以对应到发布包。

## 21. 最终产品愿景

完成后的《Leo的地牢围攻》应该在第一眼、第一刀和第一局结束时分别给玩家三个明确答案：

- **第一眼**：这不是原作的简单换皮，而是 Leo 的专属地牢世界。
- **第一刀**：武器有重量、敌人有材质、命中有结果，且反馈克制、不吵闹。
- **第一局结束**：离线也能留下属于自己的远征历史，并愿意继续挑战下一次围攻。

这三点同时成立，个人专属版才算真正建立完成。
