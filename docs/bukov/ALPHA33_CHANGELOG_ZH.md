# 逃离布科夫 Alpha 33 阶段封存说明

Alpha 33 收口的是实时输入、响应式 HUD、背包信息层级和运行时文字复用。
本文件所在提交是本阶段唯一源码身份；分发包必须由该干净提交重新构建，
不得复用 Alpha 32.9 的应用缓存。

## 玩家可见修复

- 鼠标左键开火不再同时触发界面点击；经典模式的点击语义保持不变。
- 打开或关闭背包时清除旧输入边沿。持续按住开火键或鼠标跨过背包关闭，
  不会补发一枪；释放并重新按下后正常恢复射击。
- macOS 暂停按钮与右侧 HUD 使用同一几何合同，固定保留 4 像素间距。
- iPhone、iPad 与 Mac 窗口统一使用响应式保留区；导航、威胁、任务、
  交互、武器、弹药、医疗、Boss 文案均按可用宽度收口。
- 背包物品行增加稀有度色条和深色图标衬底，低亮度枪械图标不再融入底色。
- Bukov 设置页使用专用实时动作目录，不再把宿主经典动作全集带入玩家路径。
- 敌人动作、三类地表脚步、Motion Token、触控与控制器合同补齐自动门禁。

## 根因级修复

- `KeyEvent` 增加逐事件 raw 消费，实时开火与 UI 模拟点击只会走一条路径。
- `RealtimeInput` 增加界面转场 release latch，覆盖背包真实调用顺序和持续按住输入。
- `RenderedTextBlock` 仅在渲染子节点仍存活且仍属于当前组件时复用相同文本；
  `FloatingText` 复用时恢复文字、颜色、透明度和图标方向。
- HUD 文案拟合使用按文本、宽度、缩放和字体合同失效的缓存，稳定帧不再重复
  正则归一化和尺寸计算。
- CJK 宽度判断改用稳定 Unicode 区段，避免调用 RoboVM 2.3.24 不提供的
  `Character.UnicodeScript.of`。

## 自动验收

- Core：1159 项。
- Desktop：10 项。
- iOS：11 项。
- 三模块均以 `--rerun-tasks` 无缓存执行。
- 音频、敌人图集、物品图集、本地化、原创视觉、六主题结构、UI 图集、
  UI/Motion Token、法律、地图可见性、战利品可发现性、内容规模和 RoboVM API
  兼容门禁通过。

## 仍不应宣称完成的事项

Alpha 33 是阶段封存，不是 v2.0 的 100% 最终封板。物理 iPhone、实体控制器、
当前提交双端各 30 分钟长测、五模式真人完整路线、10 名玩家复玩测试、
三人音频盲测，以及 24 张最终原创环境母图仍需独立证据。
