# Alpha 32 开发候选变更说明

状态：开发候选，尚未封存
基线：Alpha 31 `a91461c5ba57aedb76f07acd741b749100425fb2`

## 本轮已经接入

- 命中不再固定视为躯干：普通敌人区分躯干和肢体，Boss 只在暴露阶段
  接受独立弱点命中。
- 玩家与敌人改用同一套护甲覆盖、穿透、耐久结算；删除敌人固定比例的
  事后减伤。
- 换弹可被开火、交互、治疗、丢弃和打开背包取消，不消耗后备弹；移动不打断
  换弹，避免 iOS 持续摇杆输入导致永远无法完成换弹。
- Boss 阶段切换使用六帧专属过渡；阶段击破和弱点击杀提供 200 ms、
  0.3 倍速的纯表现慢动作，不修改实时模拟时钟。
- 枪械每次射击都会累积热量和污损并损耗耐久；热量随时间冷却，三项状态
  会影响散布。耐久和污损跨局保存，热量在新一局清零。
- 背包显示当前枪械的实时耐久、污损和热量，不再显示入局时的旧快照。
- iOS 背包改用触控关闭提示，物品分类使用当前语言，不再显示桌面 `TAB`
  提示或中英文混杂的分类代码。
- 设置页增加键盘和手柄按键绑定入口，复用现有完整绑定编辑器。
- iOS 横屏 HUD 改为紧凑单行摘要，移动端镜头拥有独立可视范围，触控摇杆
  增加空闲、按下和禁用三种透明度反馈。
- 六主题视觉门禁增加灰度局部结构比较，纯换色资源无法再伪装成独立主题。
- 新增可恢复的 macOS/iOS 干净验收档案脚本；重置会先备份，不删除用户档案。
- 玩家射击的宽阶段查询改为可复用的 4×4 格空间桶，只把与射线 AABB
  相交的敌人交给精确命中计算；出生、移动、死亡、Boss 绕过和场景释放都会
  同步索引，并保持原有稳定命中顺序。
- 硬地、水面和金属三类脚步声已按真实地形与主题环境规则显式路由；新增
  6 个原创变体的声学差异门禁，防止素材文件虽然合法却退化成听感近似。
- 敌人 AI 补齐确定性的巡逻、追击、搜索、返巡逻闭环；视觉和听觉记忆分离，
  丢失视野后只搜索最后所见位置，不再隔墙跟随玩家实时坐标，搜索与巡逻状态
  可随 Raid 检查点恢复。
- 四个音频总线新增每总线最多 6 个活跃声源的优先级预算；统一 UI 音效入口
  已真实接入，淘汰或超时会停止底层播放实例。玩家枪声和撤离提示的保护规则
  已建立，World 私有播放入口仍待后续统一。
- 仓库/配装主窗口开始使用统一 UI 动效调度器：标题与强调线按设计令牌入场，
  动画不拦截键鼠、手柄或触控输入；开启“减少动态效果”时首帧直接到终态。

## 兼容性

- 旧枪械存档没有热量或污损字段时按冷却、清洁状态读取。
- 清洁枪械保持旧版经济指纹格式，避免历史结算回放失配。
- 当前变更不修改固定步长、随机数顺序或全局时间倍率。
